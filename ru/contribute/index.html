    Анонимные пожертвования приветствуются.

    Пожертвования финансируют .onion-хостинг Tor, регистрацию домена, защищённый почтовый хостинг и работу выходных узлов. Каждый цент учтён ниже. Прибыль никогда не извлекается.

    Пожертвовать Monero (XMR) Пожертвовать Bitcoin (BTC)

    Текущие цели

    • ✓ VPS для .onion-хостинга профинансирован
    • ✓ Домен anonymousplanet.net — оплачен до 2029 года
    • ○ Надёжный почтовый хостинг
    • ○ VPS для общих сервисов проекта

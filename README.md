**Как читать или экспортировать руководство**

- **В браузере:** [Путеводитель автостопщика](https://dataarchitectpro.github.io/thgtoa/) (сайт на GitHub Pages). После локальной сборки можно открыть `site/ru/guide/index.html` напрямую.
- **Локальный HTML-просмотр:** из корня репозитория, при установленных Python 3 и [MkDocs Material](https://squidfunk.github.io/mkdocs-material/getting-started/) (`pip install mkdocs-material`), выполните `mkdocs serve` и откройте URL из терминала (например `http://127.0.0.1:8000`).
- **PDF:** светлая и тёмная версии — в [выпусках GitHub](https://github.com/DataArchitectPro/thgtoa/releases). Сборка: `python scripts/build_guide_pdf.py --both`.
